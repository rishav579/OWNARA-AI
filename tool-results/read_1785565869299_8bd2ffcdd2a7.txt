   589→   589→// ─── Execution Contract Engine ──────────────────────────────────────────────
   590→   590→// Immutable contracts generated before ANY irreversible tool execution.
   591→   591→// Every approval references a Contract (not mutable task state).
   592→   592→// Contracts are versioned — modifications create V2, V3, etc.

   605→   605→  parentContractId String? // ID of the previous version (for version chain)
   606→   606→

   608→   608→  status          String   @default("draft") // draft | pending_approval | approved | rejected | expired | superseded
   609→   609→

   611→   611→  goal            String   // What the employee is trying to achieve

   617→   617→  businessImpact  String   // text — financial/reputational/operational impact
   618→   618→  affectedSystems String   @default("[]") // JSON array of systems affected (e.g., ["invoices", "reminders"])
